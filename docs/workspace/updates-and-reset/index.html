Updates and reset

Crosscheck checks for a new version each time it starts, and you can check at any time from the menu. You can also reset the app to a new install. The title bar shows the version that runs, such as v0.5.0, next to the Crosscheck name.

Install an update

Section titled “Install an update”

When a new version is available at startup, the “Update available” dialog opens. It names the new version and your version.

  1. Select “Install and Restart” to download the update, install it, and restart the app.
  2. Or select “Later” to keep your version for now.

The startup check is silent when you have the latest version or when your computer is offline.

Check for updates

Section titled “Check for updates”
  1. Open the menu:
    • On macOS, open the Crosscheck app menu.
    • On Linux, open Help.
  2. Select “Check for Updates…”.

When you have the latest version, the app says so.

Read-only location

Crosscheck cannot update itself from a read-only location. On macOS, move Crosscheck to Applications, open it from there, and check again. On Linux, move the AppImage to a writable folder. You can also run the install command again.

Read the app details

Section titled “Read the app details”

Select About in the same menu. The About window shows the version, the platform, the data folder, and a link to the Crosscheck website.

Reset Crosscheck

Section titled “Reset Crosscheck”

A reset deletes all the settings, bound repositories, review history, drafts, logs, and AI sessions of Crosscheck. The app then restarts as a new install. Your gh sign-in and the worktrees in your repositories stay.

  1. In the same menu, select “Reset Crosscheck…”.
  2. Read the warning.
  3. Select “Reset and Restart”, or select “Cancel”.

Danger

You cannot undo a reset. To keep your configuration, export it first.
