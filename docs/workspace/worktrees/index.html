Worktrees and terminals

Each PR opens in a git worktree, a separate working folder, so your current branch stays where you left it. The “Worktrees and terminals” view lists the worktrees on top and the terminal sessions below. Use it to open, update, or remove worktrees, to work in a shell or an AI session, and to free disk space.

To open the view, select “Worktrees and terminals” in the Workspace section of the sidebar.

Read the worktree list

Section titled “Read the worktree list”

The list groups the worktrees by repository. Each row shows the PR, the account, the status, the size, and the last use. The header shows the number of worktrees, their total size, and the number of sessions.

Status What it means
Ready The checkout is at the current head of the pull request
Outdated The pull request has new commits
Dirty The checkout has local changes, so the app does not update it
Missing The folder is gone. The app removes its leftover git records

Drag the separator to resize the list and the terminal. Select “Worktrees” to fold the list.

Open a worktree

Section titled “Open a worktree”
  1. Open the “…” menu of the worktree row. In a review, use the “Worktree” menu in the header.
  2. Under “Open the worktree”, choose an editor, “File manager”, “Copy path”, or “Shell in the Terminal view”.

The first time that you open a PR in an editor or a shell, Crosscheck asks you to confirm.

Caution

A worktree holds code from the PR. Keep the workspace trust of your editor turned on when you inspect it.

To use an editor that Crosscheck does not detect, add a custom editor in Settings > Repositories:

  1. Select “Add custom editor”, and give it a name.
  2. Select “Choose…”, and choose its program: an .app on macOS, or an executable file on Linux.

The editor then shows in the “Open the worktree” menu. Crosscheck passes the worktree folder as its only argument.

Update a worktree

Section titled “Update a worktree”

When a PR has new commits that its worktree lacks, its row shows “Outdated”. Select “Update worktree” to fetch the new commits and update the checkout. The review header and the row menu of the PR Explorer have the same action. A worktree with local changes keeps its checkout.

Use the terminal

Section titled “Use the terminal”

The bottom of the view shows the terminal sessions: shells, AI sessions, and preparation commands. The sessions of a PR show under its row.

  • Select “New shell” and choose a worktree to start a shell in it.
  • Open the “…” menu of a session to “Show session”, “Open beside”, “Close pane (keep session)”, or “Open context folder” of an AI session.
  • Select “Stop session…” or “Remove session…” to end a session. Crosscheck asks you to confirm.

The view shows up to four sessions at once. Closing a pane keeps the session running. The “First run” group holds the first-run sessions of the AI CLIs.

Use a session when an AI CLI asks a question, such as a sign-in, or when you want to read its output.

Remove worktrees

Section titled “Remove worktrees”
  • Select “Remove worktree…” in the row menu to remove one worktree. Its sessions stop.
  • Select “Remove N unused…” above the list to remove the worktrees that you did not use for 14 days. Worktrees with local changes stay.
  • In a repository group, select “Remove N clean…” to remove the worktrees with no local changes.
  • In a repository group, select “Remove N with changes…” to remove the worktrees with local changes. This discards the changes.

Each removal asks you to confirm. Your drafts and review marks stay.

In Settings > Repositories, “Worktree cleanup” sets whether a worktree stays (“Keep”) or goes (“Delete”) when you close a review. A worktree with local changes always stays.

Free disk space

Section titled “Free disk space”

Each AI review and each AI action writes a run folder. When a new review of a PR finishes, Crosscheck deletes the earlier runs of that PR.

  1. Select “Disk cleanup”.
  2. Select “Clean…” next to one of these:
    • “Delete runs of closed PRs” deletes the runs of merged and closed PRs.
    • “Delete run folders older than 30 days” deletes the run folders that did not change in that time.
  3. Confirm the deletion.

A cleanup deletes only the run folders of your account that no review, AI action, or chat uses. It does not touch worktrees, review marks, or drafts.
