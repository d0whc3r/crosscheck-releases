Accounts

Crosscheck can use each GitHub.com account that the GitHub CLI knows. Each account keeps its own settings, repository bindings, worktrees, reviews, history, and draft comments.

Switch account

Section titled “Switch account”
  1. Sign in to each account with gh auth login.
  2. In Crosscheck, select your account at the right end of the title bar.
  3. Under “GitHub accounts in gh”, choose the account that Crosscheck uses. The tag “gh active” marks the active account of gh.

After the switch, Crosscheck opens the start page and closes every result window. Crosscheck keeps your choice. It does not change the active account of gh.

The drafts of each account stay when you switch. When an account has drafts that you did not post, the menu says so and links to Drafts.

Note

git uses your own git credentials, not the account of Crosscheck.

The post dialog shows the account that posts each review.

Fix a signed-out account

Section titled “Fix a signed-out account”

When gh has no valid token for the chosen account, the title bar says so, and Tools & connections shows “Account signed out”.

  1. Run gh auth login for that account in a terminal.
  2. Select “Check connections”.

Or select “Use the active gh account” to continue with the account that gh uses now.
