Ask about the code

Ask the AI about lines of the diff, about a comment, or about the whole PR. Compare the answers of several engines, and use an answer as the text of a comment. Nothing goes to GitHub until you post the review.

Ask about selected lines

Section titled “Ask about selected lines”
  1. Select a line or a range in the diff. The comment composer opens.
  2. Choose an action:
    • “Explain change”
    • “Draft inline review comment”
    • “Verify edge case”
  3. Or type a question in “Ask AI about these lines”, and select “Ask”. Enter sends the question, and Shift+Enter adds a line.

An answer can take up to five minutes. “Stop” ends an answer that still runs. Each new question sends the earlier questions and answers of the lines as history. “Clear chat” starts again.

The engine button next to the actions opens “AI actions engine”. The engine applies to every AI action and question of the diff. Select “Use engine A” to return to the default.

Compare engines

Section titled “Compare engines”
  1. Select “Compare with another engine”.
  2. Choose the engine. Repeat to add more engines.
  3. Ask the question. Each answer shows its engine. When the composer is wide enough, the answers sit side by side.

Use an answer as a comment

Section titled “Use an answer as a comment”

Select “Use as comment” to put an answer into the text field of the composer, where you edit it. When the field already has text, the button says “Replace comment text”.

Improve a comment with AI

Section titled “Improve a comment with AI”

Each draft has AI actions:

Draft Actions
A new comment or a finding “Summarize”, “Verify the finding”, “Challenge the finding”, “Explain”, “Shorten”, and “Add suggestion”
A reply to a thread “Draft reply”, “Summarize”, “Explain”, “Shorten”, and “Expand and justify”
A posted comment “Verify the finding” and “Explain”, under “AI actions”

“Challenge the finding” looks for a counterexample in a fresh session. Type in the “Ask or instruct the AI” field to ask your own question about the comment.

Under an answer:

  • Select “Use this answer” to replace the comment text with it.
  • Open the answer menu to edit the answer, “Refine with AI”, or “Show changes”.
  • Select “Remove answer” to delete it.

On a reply, the answer of “Draft reply” proposes the text of the reply. Select “Replace the reply” to use it.

Get follow-up questions

Section titled “Get follow-up questions”
  1. In Settings > AI review, turn on “Suggest follow-up questions under an answer”.
  2. Choose the “Follow-up questions engine”. A small, fast model is enough.
  3. Under the answer of a comment action, select “Suggest questions”. The engine sends up to three short questions.
  4. Select a question to put it in the question field, edit it, and send it.

Nothing runs until you select “Suggest questions” or send a question. With the setting off, the button does not show.

Read a long answer in short form

Section titled “Read a long answer in short form”
  1. Open the menu of the answer of a comment action, and select “Concise view”. The short version shows under “Summary”, with the engine name.
  2. Select “Full view” to read the whole answer again.

The app keeps the short version with the answer, so a second click needs no new request. When the answer changes after the summary, the summary says so, and “Regenerate” writes a new one. “Use this answer” always uses the full answer.

Chat about the PR

Section titled “Chat about the PR”
  1. Open the “Chat” tab of the side panel.
  2. Ask a question about the repository and the PR. “Engine of the PR chat” sets the engine.

The “Ask questions” block of the Overview tab has starter questions, such as “What are the riskiest changes?”. Select “Open chat” to ask your own.

Crosscheck saves the chat in the history. Each answer records the commit that the AI read, and it says so when it refers to an older commit.

Ask about the review draft

Section titled “Ask about the review draft”

In the Post review dialog, “Ask AI about the review” helps you edit the review before you post it.

  • Ask the AI to change the body, or select “Shorten the body” or “Expand the body”.
  • Read the proposal, and select “Apply” or “Discard”. “Undo” reverts an applied proposal.
  • Select “Refine with AI” on a draft to refine that comment.
