Troubleshooting

Find your problem in the table, and try the fix. If the problem continues, report a bug.

Common problems

Section titled “Common problems”
Problem What to try
Tools & connections shows a required tool as “Not found” Install the tool, make it available in your login shell, and select “Check connections”
GitHub shows “Signed out” Run gh auth login in a terminal, then select “Check connections”
GitHub shows “Account signed out” Run gh auth login for that account and select “Check connections”, or select “Use the active gh account”
A PR page shows “Repository not bound” Select “Bind repository” to choose the clone, or “Clone repository” to clone it. See Connect GitHub and a clone
Crosscheck does not find your clones Add their parent folder as a scan root in Settings > Repositories, then select “Scan now” on the Repositories page
An AI tool shows “Not found” Install the CLI so that your login shell finds it, then select “Check again” under AI tools in Tools & connections
A review says that an AI CLI is not signed in Select “Sign in in Terminal” in the notice, sign in inside the session that opens, then select “Retry”. Codex uses its own sign-in for Crosscheck, so a sign-in in another terminal does not count
A review says that macOS blocked the Codex sandbox helper Check the detected path and version in the notice or in Tools & connections. If you updated Codex or moved it, select “Check Codex and retry”
Codex reports Operation not permitted when it runs pnpm or a test Run the test as a preparation command, and read its output in the Worktrees and terminals view. Preparation commands run outside the review sandbox, after your approval
An AI review stalls, or a session needs attention Open the session in the Worktrees and terminals view, and look for a sign-in prompt, a trust question, or an error
The worktree is out of date Select “Update worktree” in the banner of the review. When the worktree has local changes, select “Discard local changes” first
The diff says that it is larger than 64 MiB Crosscheck does not show a diff of that size. Review the PR on GitHub, or open its worktree in an editor
A deleted line cannot take a comment in “Since last review” Switch to “Full”, so that the line matches the review positions of GitHub
A post result is unknown Select “Check GitHub” in the Post review dialog, then “Post again” or “Remove the posted drafts”. See Post to GitHub
“Check for Updates…” says that Crosscheck runs from a read-only location Move the app to Applications on macOS, or the AppImage to a writable folder on Linux. See Updates and reset
The disk fills up Open “Disk cleanup” in the Worktrees and terminals view. See Free disk space

Investigate a failure

Section titled “Investigate a failure”

Turn on debug mode to read the live log. See History and logs.

As a last step, “Reset Crosscheck…” returns the app to a new install. See Updates and reset.

Report a bug

Section titled “Report a bug”

Report a bug with:

  • the app version, which shows in the title bar,
  • the operating system,
  • the steps that reproduce the problem,
  • the error text.

Caution

Remove tokens and private code from anything that you share.
