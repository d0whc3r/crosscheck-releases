Privacy and safety

Crosscheck keeps your work on your computer, posts to GitHub only when you select a post button, and sends PR context to an AI provider only when you start an AI task. It treats the code and the text of each PR as untrusted.

What stays on your computer

Section titled “What stays on your computer”
  • Settings, repository bindings, drafts, review marks, the Revisit list, review history, and the run folders of AI reviews.
  • The data of each GitHub account lives in its own folder.
  • Run folders contain diffs and PR text, also of private repositories. To delete them, see Free disk space.
  • The app writes no token and no secret to disk.

To delete all the data of the app, see Reset Crosscheck.

What goes to GitHub

Section titled “What goes to GitHub”

Crosscheck changes GitHub only after these actions:

  • You post a review. See Post to GitHub.
  • You resolve or reopen a conversation.
  • You mark a file of a PR as reviewed. GitHub then shows the file as viewed for you.
  • You merge a stack.

“Mark as reviewed”, drafts, Revisit notes, briefings, review plans, quizzes, and batches stay local.

What goes to an AI provider

Section titled “What goes to an AI provider”

An AI review, an AI action, a chat, a briefing, a review plan, or a quiz sends PR context to the provider behind the CLI that you choose, with your provider account. Use Context preview to see and trim what a review sends.

Your GitHub token

Section titled “Your GitHub token”

Crosscheck reads the token from gh and keeps it in memory. The token does not reach the AI CLIs, the logs, or the error messages.

Untrusted PR code

Section titled “Untrusted PR code”

A PR can come from anyone, also from a fork. Crosscheck protects your computer in these ways:

  • It never runs code of the PR by itself. A preparation command runs only after you approve it for that PR head.
  • git hooks are off on every git call and in each shell that Crosscheck starts.
  • The AI CLIs start outside the worktree, so the PR cannot configure them.
  • The AI engines get no GitHub token and cannot post.
  • The app shows PR text as text, opens only GitHub links, and loads images only from GitHub.
  • The HTML preview runs no page script until you allow it, and the page cannot reach the network.
  • A desktop notification of new watch matches shows only a count.

Caution

When you open a worktree in an editor, keep workspace trust turned on. A shell in a worktree can still run shell hooks that read files of the PR.
