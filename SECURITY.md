# Security policy

Report suspected vulnerabilities privately when GitHub offers private reporting for this repository. Keep exploit details, tokens, and private repository content out of public issues.

## Report a vulnerability

Open the repository's [Security tab](https://github.com/d0whc3r/crosscheck-releases/security). If "Report a vulnerability" is available, use it to contact the maintainer privately.

If private reporting is unavailable, open an issue that asks for a private reporting channel. Do not include vulnerability details in that issue. Wait for a private channel before sharing the report.

In a private report, include the affected app version, operating system, reproduction steps, expected impact, and a minimal example. Remove unrelated credentials and private code. State whether the issue involves PR content, AI output, editor integration, or a terminal session.

## Scope

Crosscheck is in early development. Include the version or source commit in each report so the maintainer can identify the affected code.

For crashes, usability problems, and other bugs without a security impact, use the [bug report form](https://github.com/d0whc3r/crosscheck-releases/issues/new?template=bug_report.yml).
